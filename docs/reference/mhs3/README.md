# Monster Hunter Stories 3 screenshots

These frames back the rules in [../../shading-style-guide.md](../../shading-style-guide.md) and [../../anatomy-manual.md](../../anatomy-manual.md). Both documents cite them by number, for example "MHS3-09". Use the trait each frame teaches. Do not reproduce the characters, costumes, monsters, or emblems.
