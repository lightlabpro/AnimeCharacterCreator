## What this means for head_mhs3_n56 (q20)
Nothing about anatomy or drawing. The one usable idea for the creator: a character's expression set should show
the arc's contrast ("before and after" mirror scenes) - the same face must read clearly in opposite states (the
expression presets need strong, distinct reads, not near-duplicates). No rule changes the head.
