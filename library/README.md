# Asset library

Claude fills this tree from [../docs/CLAUDE_BUILD_PROMPT.md](../docs/CLAUDE_BUILD_PROMPT.md). The creator imports this folder, or one category folder inside it.

`humanoid/` is shared by humans and human-beasts. `robot/` and `full_beast/` do not mix with it. Each pack folder holds a mesh, a glTF export, and `pack.json`. The folder layout is specified in [../docs/CHARACTER_MAKER.md](../docs/CHARACTER_MAKER.md).
